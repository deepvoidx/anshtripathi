# Ansh Tripathi — Digital Presence & Creator Strategist

Responsive personal portfolio website for Ansh Tripathi.

## Included
- Responsive desktop / tablet / mobile layout
- Glassmorphism + editorial visual system
- Circular personal portrait treatment
- Downtown Vines account case study with explicit account identity and handle
- Aman Kumar creator case study with Instagram + YouTube identity
- Capabilities, about and contact sections
- WhatsApp + phone contact CTA
- Reduced-motion support

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy
The folder can be deployed to GitHub Pages, Cloudflare Pages, Netlify, Vercel or any static host.
